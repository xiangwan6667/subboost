# Miu Subscription Support Implementation Plan

> **For agentic workers:** Use test-driven development and execute the tasks inline. Push only with explicit authorization.

**Goal:** Import and generate Miu nodes compatible with the upstream Mihomo outbound.

**Architecture:** Validate and normalize Miu configuration once for YAML imports, links and saved nodes; integrate with existing parser registry and generation pipeline. Keep the upstream protocol implementation outside SubBoost.

**Tech Stack:** TypeScript, Vitest, js-yaml, existing React UI.

**Spec:** `docs/superpowers/specs/2026-11-01-miu-design.md`

## Review Focus

- Preserve PSK bytes, including percent encoding, numeric YAML credentials and Unicode.
- Preserve explicit `udp: false`, certificate pins and leading-zero REALITY short IDs.
- Reject missing or too-short PSKs and malformed REALITY options without leaking credentials.
- Respect client-fingerprint defaults and explicit global fingerprints.
- Check generated YAML with a Miu-enabled client and document any unavailable live validation.

## Tasks

1. Add failing end-to-end tests for TLS and REALITY YAML import/generation, invalid saved nodes and fingerprint handling; implement Miu typing, validation and generation.
2. Add failing link/Base64 tests for the documented compatibility syntax, invalid inputs and secret redaction; register and implement the parser.
3. Update source hints and protocol documentation; run focused and complete test suites, lint and type checks; inspect the final diff and validate with a Miu-enabled client if available.
